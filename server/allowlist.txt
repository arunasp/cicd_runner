# to run, per-project, inside whichever /projects/<name> directory the
# caller selects. One name per line; blank lines and '#' comments are
# ignored.
#
# This file lives under /app in the image (COPY'd, not bind-mounted --
# unlike LocusAI's own allowlist.txt, which lives under the /workspace
# bind mount and can be hot-edited on the host). Changing this list
# needs an image rebuild here, since there's no single project
# directory this file could live under instead -- it's shared across
# every mounted project.
#
# `docker` being allowlisted already sets this container's privilege
# ceiling at "root-equivalent on the host" (that's the entire reason
# this container exists, separate from every project's own service --
# see Dockerfile and bash_mcp_server.py's docstring). Everything below
# is narrower than that, so none of it raises the actual ceiling
# further; it's here for genuine per-project pipeline needs, not
# because each entry was independently risk-assessed against a lower
# bar than docker itself already sets.
